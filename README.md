# Resource Pack Converter

Aplicativo Android para converter pacotes de recursos do Minecraft Java Edition para Minecraft Bedrock / Pocket Edition.

## 🎮 Como funciona

1. Escolha um Resource Pack do Minecraft Java em formato `.zip`.
2. Inicie a conversão.
3. Aguarde o aplicativo converter os arquivos.
4. Aplique o pacote no Minecraft Pocket Edition.

## 📦 Compatibilidade

O aplicativo foi desenvolvido originalmente para converter Resource Packs do Minecraft Java para o formato utilizado pelo Minecraft Pocket Edition.

Pacotes 16x16 são recomendados. Algumas texturas ou recursos de versões mais recentes podem não ser compatíveis.
